# 隐私说明

一句话：**不联网、不上传、不收集。** 下面是要点。

## 插件自己会做什么

- 读工作区里的 `todolist.json`（通过 DSH 的只读文件接口），订阅它的变化。
- 通过 `/todo op <json>` 命令写回这个文件（原子写、带版本冲突检测）。
- 在面板里操作时，往当前会话注入**一条用户消息**，让助手知道改动；模式可选（下一轮携带 / 立即唤醒 / 不通知），可在设置页关掉。
- 在 `%TEMP%\dsh-todo-tool-status.json` 写一行注册诊断（工具/技能是否注册成功、错误文本、时间）。

## 不会做什么

- 不发网络请求，不加载远程脚本/字体/图片；
- 不读工作区以外的文件；
- 不写工作区以外的文件（诊断文件在系统临时目录）；
- 不收集使用数据、不做遥测；
- 不修改会话日志的结构（只注入标准消息对象）。

## 你的计划内容会去哪

- 存在你自己工作区的 `todolist.json` 里，跟着你的 git / 备份策略走；
- 开启通知时，**改动描述**（例如「把 X 标成了 completed」）会进入当前会话，进而进入模型上下文；
- 关掉通知（设置页 → `不通知`）后，面板照常保存，助手不会被告知。

## 卸载

卸载插件不会删除 `todolist.json`，也不会自动清理 `%TEMP%` 里的诊断文件（可以手动删）。
